# 鱼酱书签助手（Chrome 扩展）

侧边栏工具：搜索书签、查重、清理空文件夹，并给出合并建议。

- 右上角可切换 **中文 / English / Français**（默认中文，偏好会记住）
- 视觉基于全局 skill（`frontend-design` / `ui-ux-pro-max` / `design-taste-frontend`）：扁平亮色、品牌蓝主色、Plus Jakarta Sans。

## 功能

- **目录**：浏览完整书签树；每条支持重命名、删除，并拖到其他文件夹
- **概况**：书签 / 文件夹 / 域名统计，域名分布与偏大文件夹
- **整理建议**：
  - 重复网址：单组或一键去重（每组保留第一条）
  - 空文件夹：单删或全部删除
  - 过小文件夹（≤2 项）：合并到上级
  - 名称重叠文件夹：选择合并方向
- **搜索**：按标题、网址、文件夹路径即时搜索；打开 / 移动 / 删除

## 安装（开发者模式）

1. 打开 Chrome → 地址栏输入 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本目录：`chrome-bookmark-assistant`
5. 点击工具栏图标，或任意页面打开侧边栏即可使用

首次使用需授予书签权限（加载扩展时已声明）。

## 权限说明

| 权限 | 用途 |
|------|------|
| `bookmarks` | 读取与整理书签 |
| `sidePanel` | 侧边栏界面 |
| `favicon` | 显示站点图标 |
| `tabs` | 在新标签打开书签 |

所有操作均在本地完成，不会上传书签数据。

## 安全提示

删除、合并、去重会**直接改写** Chrome 书签。重要数据建议先导出备份：

`Chrome 菜单 → 书签 → 书签管理器 → ⋮ → 导出书签`
